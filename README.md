# iCeberg — kit vidéo

Boîte à outils des vidéos d'astuces iPhone @iphoneiceberg (faites par Claude).

- `logo.png` : logo iCeberg (écran de fin de chaque vidéo).
- `tutos.md` : tutos déjà publiés + idées.
- `kit/` : projet Remotion prêt à l'emploi.
  - `setup.sh` : installe tout et copie le logo.
  - `src/lib.tsx` : toutes les animations validées (titre de couverture, étapes, iPhone flottant, zoom, cartes en verre, fin avec logo…).
  - `src/exemple_demarchage.tsx` : une vidéo complète d'exemple.
  - `scripts/` : dessin des écrans iPhone (Python), sons, transcription de la voix.
  - `public/` : polices, icônes 3D, écrans d'exemple.

Ne rien mettre de privé ici : le dossier est public.
